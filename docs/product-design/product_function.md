# Product Function: ADHD Focus Task Manager

## 1. Problem Framing ($y = f(x)$)

### Baseline Input Situation ($x$)
- Traditional to-do apps display overwhelming 30-item task backlogs, mandatory deadline pickers, complex sub-project trees, and guilt-inducing overdue badges.
- Users with ADHD experience executive dysfunction and analysis paralysis when facing a massive wall of items, causing task avoidance and dopamine depletion.

### Target Output Situation ($y$)
- A radically simple, calm **ADHD Task Engine** built around **"The One Thing" (Now Mode)**.
- Quick frictionless brain dump (no forms, no mandatory dates).
- Instant task chunking ("Break it down into micro-steps < 2 mins").
- Tactile, high-dopamine completion feedback (Emil Kowalski spring physics) with a visible "Completed Today" momentum log.

### Minimal Transformation Function ($f(x) \rightarrow y$)
$$f(x) = \text{Brain Dump Quick Capture} + \text{Single-Task Focus ('Now' Seam)} + \text{Micro-Step Decomposition} + \text{Dopamine Momentum Log}$$

---

## 2. 10x Scope-Stripping

| Stripped Fluff | Retained Core Essential | Why |
|---|---|---|
| Complex project trees & nested folders | 3 States: `Now` (Active), `Later` (Queue), `Done` (History) | Eliminates organizational rabbit holes. |
| Mandatory due dates & time-of-day pickers | Optional quick 15-min momentum timer | ADHD brains think in "Now" and "Not Now", not rigid calendars. |
| Cloud sync & collaboration permissions | Instant local AsyncStorage persistence | Instant load time, zero login friction. |
| Overdue red badges & guilt notifications | Completed today counter & dopamine streak | Positive reinforcement fuels executive function. |

---

## 3. Core Capabilities
1. **The "Now" Focus Seam**: Shows exactly ONE active task at full scale with sub-steps. All other tasks remain tucked away in "Later".
2. **Quick Capture**: 1-tap input bar at top of screen for immediate thought offloading.
3. **Micro-Step Decomposition**: 1-tap button to break an overwhelming task into actionable 2-minute steps.
4. **Calm Nordic Aesthetic**: Alpha-black typography and physical spring checkboxes with zero visual noise.
