# Spec Test Contracts: Polish & Gestures

## SCEN-001: Haptics Invocation Contracts
- **Given**: An active task item or checkbox.
- **When**: The user toggles completion.
- **Then**: The haptic trigger executes without runtime errors or crashes across native and web platforms.

## SCEN-002: Rubberband Deceleration Boundary
- **Given**: Page 0 of Chapter 1.
- **When**: The user drags right.
- **Then**: Resistance scales down drag displacement progressively, preventing abrupt boundary stops.
