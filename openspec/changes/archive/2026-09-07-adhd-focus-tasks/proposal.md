# Proposal: ADHD Focus Task Manager

## Problem Statement
Standard to-do list applications aggravate ADHD executive dysfunction by presenting overwhelming backlogs, rigid calendar fields, and guilt-inducing red alerts that lead to task paralysis.

## Proposed Solution
A calm, Scandinavian-styled task manager built strictly around **"The One Thing" (Now Mode)**, frictionless quick capture, micro-step decomposition, and positive completion reinforcement.

### Deliverables
1. **The "Now" Focus Screen**: Isolates the single active task with sub-step micro-actions.
2. **Brain Dump Bar**: Fast capture with zero required metadata.
3. **Queue & Momentum Sections**: Uncluttered "Later" list and positive "Done Today" log.
4. **Offline Persistence**: Local AsyncStorage persistence for instant access.
