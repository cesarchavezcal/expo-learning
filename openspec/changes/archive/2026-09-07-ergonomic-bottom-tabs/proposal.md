# Proposal: Ergonomic Native Bottom Tabs

## Problem Statement
Top-level navigation destinations (`Library`, `Focus`, `Architecture`) currently reside in the top-right header, violating the Apple HIG single-handed **Thumb Zone** and forcing awkward reach ergonomics.

## Proposed Solution
Migrate top-level screens into an Expo Router `(tabs)` layout with a translucent bottom tab bar, native SF Symbols, and haptic feedback, while keeping the E-Ink reader in a fullscreen modal that conceals tabs.
