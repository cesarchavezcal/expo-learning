# Specification: Native Bottom Tabs Navigation

## Requirements

### Requirement 1: Bottom Thumb-Zone Navigation
Top-level navigation between Library, Focus, and Architecture MUST be anchored to the bottom tab bar.

### Requirement 2: Immersive Reader Isolation
Navigating to `/reader/[id]` MUST present a full-screen modal covering the bottom tab bar completely.

### Requirement 3: Header De-Cluttering
Screen headers MUST NOT duplicate top-level navigation links.
